This file tracks the works planned for Suraiya Anvery's website, including category, image status, metadata, write-up status, and whether each work is ready to publish.

This is a planning/content-management document. It does not automatically update the live website.

## Image Naming Convention

Each individual work/item folder should eventually use:

- main.jpg
- detail-1.jpg
- detail-2.jpg
- detail-3.jpg
- detail-4.jpg

Rules:

- main.jpg is used for cards, grids, and featured previews.
- detail images are supporting images used on individual work pages.
- Use lowercase filenames.
- Avoid spaces in filenames.
- Keep original full-quality photos outside the repo in a separate master source image folder.
- Only selected, website-ready images should be copied into assets/images/work/.
